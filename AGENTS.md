# Shay’s Space

- Public site: Jekyll on Cloudflare Pages project `garden` (`garden-euu.pages.dev`), with the private portal at `shays.space/personal`. Only `/personal` and `/personal/*` route to this Worker; the old agent URL redirects here. Zone TLS: Full (strict), minimum 1.2, TLS 1.3 and HTTPS redirects on.
- `worker.ts` / `web.ts`: Cloudflare Worker serves blog assets and authenticates every `/personal` route with owner-only Cloudflare Access JWTs.
- `personal-agent.ts`: SQLite-backed Durable Object with Cloudflare `PiHarness` + Pi Durable; persistent tasks, duplicate-safe request IDs, cancellation, and usage limits. Sandbox is disabled.
- Instinct delegates through the browser. `personal.tsx` / `personal.css`: React + assistant-ui chat and activity; `inbox.ts`: private HTML. Receipt is not completion; preserve retry IDs and report actual outcomes.
- `INSTINCT.md` is the terse handoff for Obsidian and Sunsama. Keep it current; Shay passes changes to Instinct manually. Exclude it from blog assets.
- Agent and portal dates use `America/New_York`. Model uses Codex subscription OAuth. GitHub App tools read/write only `shaayaansayed/obsidian-vault`; desktop Obsidian receives edits through Git sync. Agent behavior: `agent/AGENTS.md`.
- `sunsama.ts` / `sunsama-auth.ts`: official remote MCP with OAuth credentials in durable storage; connect/disconnect and callback stay under Access-protected `/personal/integrations/sunsama`. Never automatically replay interrupted Sunsama writes.
- X publishing is local-only via official `xurl`; check `xurl auth status` first. Target `ShaayaanS`. Credentials stay in `~/.xurl`; never print tokens or use verbose output. The agent never posts, likes, or follows on X.
- `engage.ts` / `twitterapi.ts` / `jev.ts`: read-only X engagement engine. Crons 17:00 and 22:00 UTC pull the feed via twitterapi.io, Jev (TypeSafe System One) judges each post, and the picks show in the portal Engage tab (`/personal#engage`, stored in the Durable Object, reset daily); weekly expansion into vault `Engage/Pool.md` is paused (cron removed), run only on request. Seeds: `engage-seeds.txt`; bootstrap: `bootstrap-feed.ts`; local check: `engage-preview.ts`. Budget guard `ENGAGE_MONTHLY_CREDITS` (100k credits = $1). Secrets `TWITTERAPI_KEY`, `TYPESAFE_API_KEY`.
- Secrets stay in Cloudflare/local ignored files. Exclude backend files and this file from Jekyll assets. Keep Access protection during domain changes.
- Use Bun and mise; keep files flat. `build-personal.ts` bundles private assets into ignored `.personal/`. Check: `bun run check`, `bun run test`, `mise exec -- bun run build:blog`. Browser checks: `playwright-cli`. Deploy: `mise exec -- bun run deploy`.
